# Herstory AI Agent Workspace

本目录是《Herstory》游戏开发辅助 Agent 的知识库与协作工作区。

## 使用方式

1. 先阅读 `00_Project_Context`，了解项目定位与不可偏离的设计原则。
2. 再阅读 `01_Game_Design`，依据已有玩法、系统和产出模板开展策划。
3. 编写 Godot Demo 前，遵守 `03_AI_Instructions/Coding_Rules.md`。
4. 每次形成结论或改动方案，在相应设计文档中记录；未确认的内容标记为「待定」。

## 目录

- `00_Project_Context`：项目定位、设计支柱、世界观边界与竞品记录。
- `01_Game_Design`：GDD、玩法循环、系统设计、数值与模板说明。
- `02_Godot_Project`：预留给实际 Godot Demo 的标准项目根目录。
- `03_AI_Instructions`：Agent 角色、策划与代码协作规则。
- `04_Output`：已确认的策划案、Demo 构建与报告。
