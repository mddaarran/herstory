# 游戏总览

## 基本定位

- 项目名称：Herstory（暂定）
- 类型：女性君主历史演绎独立游戏
- 核心命题：如果一位女性君主在不同历史环境中作出不同选择，历史会如何改变？

玩家扮演一位女性君主，通过政治决策、国家管理和历史事件选择，创造一段属于自己的历史。

本作不是严格的历史模拟器，也不以复刻真实历史为目标；它强调在历史语境下演绎女性掌权者的统治与选择。

## 目标体验

- 成为女性君主，并建立自己的统治风格。
- 在信息有限、风险真实的政治环境中作出取舍。
- 通过选择改变国家发展与历史走向。
- 在终局由史官回望、记录并评价自己的统治。

## 设计边界

- 游戏重点是创造独特历史，而非单一的胜负判定。
- 君主目标提供长期方向，不应退化为机械任务清单。
- 数值变化应尽量通过事件结果和史官叙述被玩家理解，避免只呈现抽象加减值。
- 所有新增机制都应服务于“女性掌权者的历史重新演绎”。
