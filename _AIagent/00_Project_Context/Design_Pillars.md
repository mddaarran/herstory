# 设计支柱

## 1. 女性掌权者视角

玩家的身份与处境是体验核心。事件、人物关系和政治选择应反映女性君主掌权时可能面临的特殊期待、阻力与机会，但不把角色局限为单一叙事。

## 2. 决策塑造历史

玩家通过政治决策、国家管理和关键事件改变国家状态，并由此改变后续历史。选择应具有可理解的动机、风险和后果。

## 3. 有风险的行动结果

骰子用于解决行动，而非移动。玩家先决定方案和所用大臣，再以带有修正的投骰面对完全成功、部分成功、成功但付出代价或失败等结果。

## 4. 隐藏状态与叙事反馈

政治关系、派系关系、历史条件和事件条件可保持隐藏；史官负责把它们转化为可读、具有历史感的文本反馈。

## 5. 一段可被回望的统治

结局应综合君主目标、国家数据、关键选择和重大历史事件。预言完成是重大事件的完成节点，而非单纯数值达标。
